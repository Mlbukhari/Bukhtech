# bukhtech — Pi Network Marketplace

This repository contains a Next.js + Vercel Serverless scaffold for a Pi Network marketplace dApp called "bukhtech".

Features:
- Pi Browser SDK integration (authenticate, createPayment)
- Server-side Pi API integration (/v2/me, payments approve/complete/get)
- MongoDB persistence for users, products, orders
- Vendor dashboard and product CRUD
- Webhook endpoint with HMAC verification

See README in the repo for deployment instructions.
