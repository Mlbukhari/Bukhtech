# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Bukhtech, please email security@bukhtech.com instead of using the issue tracker.

## Security Best Practices

### For Users
- Always verify you're on the official Bukhtech domain
- Never share your Pi authentication credentials
- Use strong, unique passwords
- Enable two-factor authentication if available

### For Developers
- Validate all user inputs
- Use HTTPS/TLS for all connections
- Verify Pi SDK signatures server-side
- Store sensitive data securely
- Keep dependencies updated
- Report vulnerabilities responsibly

## Vulnerability Response

We take all security reports seriously and will respond promptly to address any vulnerabilities.

## Supported Versions

Only the latest version receives security updates.
